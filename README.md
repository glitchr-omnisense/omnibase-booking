# omnibase/booking

A ready-made structure for travel-agency sites on [omnibase](https://github.com/glitchr-omnisense/omnibase): trips, stays and bookings, with their confirmations and cancellations.

It is an example bundle, not a provider. It shows, and lets an agency site integrate quickly, the components it builds on:
- [omnisense/omnistay](https://github.com/glitchr-omnisense/omnistay): availability, prices and bookings of lodging, car hire and packages, through each provider (amadeus...);
- [omnisense/omnitravel](https://github.com/glitchr-omnisense/omnitravel): timetables and itineraries for the trip.
